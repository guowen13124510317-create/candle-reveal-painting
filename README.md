# 烛光 · 古画 — 新媒体艺术装置

> 一个人举着蜡烛，走向一面放映古画的屏幕。当烛光靠近，古画在烛光位置亮起、清晰显现；烛光离开，画面重新隐入黑暗。
>
> **本装置完全不需要懂编程即可安装运行。** 全部代码只有一个网页文件，用浏览器打开即可。

---

## 一、这是什么

| 要素 | 说明 |
|---|---|
| 交互方式 | 观众手持蜡烛走近屏幕，画面随烛光位置亮起 |
| 技术原理 | 摄像头识别烛火 → 计算烛火在屏幕上的对应位置 → 用光影算法让古画"被烛光照亮" |
| 运行设备 | 一台普通电脑（笔记本即可）+ 一个 USB 摄像头 + 一块屏幕（显示器/电视/投影仪均可） |
| 运行软件 | 只需要 Chrome 或 Edge 浏览器，**不需要安装任何编程软件** |

---

## 二、工作原理（三步）

```
【第1步 感知】摄像头拍摄观众区，在画面中寻找"又亮又暖"的光点（烛火）
       ↓
【第2步 映射】把烛火在摄像头画面里的位置，换算成屏幕上的位置（可标定）
       ↓
【第3步 呈现】屏幕上的古画平时保持昏暗；在烛光对应位置画一个暖色光斑，
              光斑内的古画完整显现、色彩清晰，光斑外仍是暗夜
```

- 烛火离屏幕越近（在画面里越大越亮），光斑越大、越亮 → 产生"走进屏幕，古画清晰显现"的效果
- 支持 **1~2 支蜡烛**同时互动
- 画面带烛火闪烁、光尘浮动、暗角，呈现电影质感

## 四、场地布置

```
        ┌─────────────────────────────┐
        │   屏幕 / 投影幕（放映古画）      │
        │  平时昏暗，烛光一照就亮          │
        └──────────────▲──────────────┘
                       │ 摄像头架在这里（屏幕上方，
                       │ 镜头朝下拍摄观众区）
        ┌──────────────┴──────────────┐
        │         观众走道              │
        │   观众手持蜡烛从远处走近屏幕     │
        └─────────────────────────────┘
```

要点：
1. 摄像头放在屏幕**上方或侧面**，朝观众区拍，画面里**尽量不要拍到屏幕本身**（屏幕光会干扰识别）。
2. 展厅保持黑暗，烛火是画面里最亮的东西，识别最稳定。
3. 电脑放在幕后（屏幕背面），用 HDMI/无线投屏连接屏幕。
4. 屏幕亮度不要正对摄像头。

## 五、如何运行（零基础步骤）

### 第 1 步：安装一个免费小工具（一次性）

只需要 **Python**（用来把网页"开"成一个小网站，才能用摄像头）：
- Windows：打开 https://www.python.org/downloads/ 下载安装，**安装时务必勾选 "Add Python to PATH"**
- Mac：打开终端（Spotlight 搜"终端"）输入 `brew install python3`（没装 brew 就直接用下面的 Python 官网安装包）

### 第 2 步：打开本文件夹，双击启动

- **Windows**：双击 `start_server.bat`
- **Mac / Linux**：双击 `start_server.sh`（首次需右键 → 打开方式 → 终端），或在终端里执行 `bash start_server.sh`

会自动弹出一个黑窗口（这是服务器，别关），稍后浏览器自动打开装置页面。

> 如果没有自动打开，手动在浏览器地址栏输入：`http://localhost:8000/`

### 第 3 步：选模式体验

页面顶部有 5 个按钮：

| 按钮 | 作用 |
|---|---|
| **自动演示** | 默认模式。自动演示"一人持烛走近、古画显现"的全过程，无需任何设备 |
| **演示模式** | 鼠标/手指当蜡烛：移动鼠标，光就亮到哪 |
| **摄像头模式** | 真实蜡烛模式，用摄像头识别烛火 |
| **标定设置** | 打开右侧设置面板，调参数、对坐标（见下一节） |
| **安装模式** | 隐藏全部界面，只留画面，正式展出用（按 I 或 Esc 退出） |

先点"自动演示"和"演示模式"确认画面效果正常，再接摄像头。

### 第 4 步：接摄像头，用真实蜡烛

1. 点击**摄像头模式**，浏览器会询问摄像头权限 → 点"允许"。
2. 打开**标定设置**，右侧会显示摄像头画面和识别到的烛火十字标记。
3. 点一支蜡烛走到摄像头前，确认十字对准烛火。
4. 调节**X 偏移 / Y 偏移 / 坐标缩放 / 镜像画面**，让"烛火位置 → 屏幕亮起位置"对应正确（例如烛火在画面左侧，光斑就应出现在屏幕左侧）。
5. 点**保存设置**，然后点**安装模式**，正式开演。

## 六、标定参数说明（面板）

| 参数 | 默认 | 说明 | 什么时候调 |
|---|---|---|---|
| 亮度阈值 | 200 | 多亮才算"烛火"。环境太亮识别乱跳 → 调高 | 识别不到/识别乱跳 |
| 暖色阈值 | 25 | 要多"暖"才算烛火，滤掉白色灯光 | 白灯被当成烛火 → 调高 |
| 平滑度 | 0.35 | 光斑跟随的稳定度。越小越稳、越大越跟手 | 光斑抖动 → 调小 |
| 光照半径 | 0.22 | 烛光在屏幕上照亮的范围（相对屏幕宽度） | 效果太聚/太散 |
| 光照强度 | 1.0 | 烛光亮度倍率 | 亮了/暗了 |
| 背景暗度 | 0.13 | 无烛光时古画的暗度（越小越暗） | 想更暗/更亮 |
| X / Y 偏移、缩放、镜像 | 0 / 0 / 1 / 开 | 烛火坐标 ↔ 屏幕坐标的对位 | 光斑位置不对 |
| 光尘粒子 | 40 | 烛光里的浮动光尘数量 | 想更热闹/更干净 |

## 七、常见问题（排查表）

| 问题 | 原因与解决 |
|---|---|
| 页面黑屏 / 古画不显示 | 1) 确认 `assets/painting.jpg` 文件在（和网页同一文件夹的 assets 里）。2) 确认是用 `http://localhost:8000` 打开而不是直接双击 html 文件 |
| 点摄像头模式没反应 / 显示无法打开摄像头 | 必须通过 `http://localhost:8000` 打开页面（localhost 才被浏览器信任）；检查浏览器地址栏是否是 http 开头；换 Chrome 试试 |
| 识别不到烛火 | 关灯让环境更暗；烛火离摄像头近一点；把"亮度阈值"调低到 160~180 |
| 光斑乱跳 | 调高"亮度阈值"和"暖色阈值"；把"平滑度"调小到 0.15；检查是不是屏幕/白灯被当成烛火 |
| 光斑位置不对 / 上下颠倒 / 左右反 | 调"镜像画面"和 X/Y 偏移、坐标缩放 |
| 画面太亮没有"暗夜感" | 把"背景暗度"调到 0.08~0.1；把房间灯关掉 |
| 投影仪投射时被摄像头拍到 | 调整摄像头角度，让它拍不到屏幕/投影区 |
| 用了 LED 蜡烛识别不到 | LED 蜡烛普遍偏白偏暗。把"暖色阈值"调低到 5~10、"亮度阈值"调低；或选用暖黄光 LED 蜡烛 |

## 八、进阶玩法（可选）

- **换古画**：把自己的古画/名画图片命名为 `painting.jpg`，替换 `assets/` 里的文件即可（推荐横版高清图，自动铺满屏幕）。
- **两支蜡烛**：程序天然支持 1~2 个光斑，两个人各举一支蜡烛可同时点亮不同区域。
- **声音**：可另用投影仪/音箱播放环境音乐；烛光与呼吸声同步会更动人。
- **更有仪式感**：给观众准备统一的黑色长袍/烛台托盘，营造"提灯人"意象。
- **Kinect / 深度相机进阶**：如需"人离屏幕越近画越亮"的精确距离感应，可后续升级深度相机（本版用"烛火光斑大小"近似距离，已经够用）。

## 九、文件说明

```

├── index.html          ← 装置程序本体（唯一需要运行的网页，所有代码都在里面）
```
